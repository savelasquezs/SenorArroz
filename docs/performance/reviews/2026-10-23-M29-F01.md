## 1. Flujo y causa raíz

1. `Dashboard.vue` muestra `GlobalDashboard.vue` o `AdminDashboard.vue`; ambos activan los composables `useDashboardPrincipalSection` y `useDashboardPrincipalSalesVsExpenses`.
2. `DashboardRightNav` cambia `branchId`, `dateRange` o `timeGranularity`. Los `watch` ejecutaban `load()` para cada cambio sin cancelar llamadas anteriores y las respuestas se asignaban sin comprobar el filtro que las originó.
3. HTTP: `GET /api/dashboard/main` para KPI/pipeline/actividad mediante `dashboardSectionApi.fetchPrincipalDashboard` → `dashboardApi.getMain`. En el backend, `DashboardController.GetMain` → `GetDashboardMainHandler` → `IOrderRepository` (agregaciones y consultas de pedidos).
4. HTTP: `GET /api/dashboard/principal/sales-vs-expenses` desde `dashboardApi.getPrincipalSalesVsExpenses`. `DashboardController.GetPrincipalSalesVsExpenses` → `GetDashboardPrincipalSalesVsExpensesHandler` → `IOrderRepository`, `IExpenseDashboardRepository`, `IBranchRepository`.
5. **Defecto comprobado en el código:** si cambia Santander→Manrique o el rango A→B mientras A sigue pendiente, una respuesta de A que llegue después de B puede sobrescribir B; igualmente puede alterar `loading`/`error`. El frontend no verificaba el contexto después de cada `await`.
6. Backend: `[Authorize(Roles = "Admin,Superadmin")]` y filtrado por sucursal/tenant siguen existiendo; esta revisión **no demuestra una fuga entre tenants en el servidor**. Se trata de consistencia visual de datos consultados legítimamente por el usuario.
7. SignalR, workers, Flutter, Next.js y agente de impresión: no forman parte de este flujo de carga; sin cambios.

## 3. Corrección preparada en rama, no integrada

- Cada nueva llamada a la sección Principal crea un `AbortController` y cancela la anterior; `signal` viaja por `fetchPrincipalDashboard`/`dashboardApi` hasta Axios. También se aplica al gráfico.
- Un contador de versión valida `success`, `catch` y `finally`; una respuesta antigua no modifica `data`, `error` ni `loading`.
- Al abandonar Principal o destruir el scope Vue se invalidan solicitudes pendientes.
- Archivos: `src/composables/dashboard/useDashboardPrincipalSection.ts`, `useDashboardPrincipalSalesVsExpenses.ts`, `src/services/MainAPI/dashboardApi.ts` y `dashboardSectionApi.ts`.
- Pruebas agregadas: `src/composables/__tests__/useDashboardPrincipalLatestOnly.test.ts` (4 casos: KPI fuera de orden, error obsoleto/desactivación, gráfico fuera de orden, destrucción scope).
