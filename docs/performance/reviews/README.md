# Informes diarios de auditoría

Cada revisión va en un documento `YYYY-MM-DD-Mxx-Fyy.md`, generado a partir de [la plantilla](../REVIEW_TEMPLATE.md) y enlazado desde [CHECKLIST.md](../CHECKLIST.md).

El informe debe referenciar código y commit concretos de cualquiera de los cinco repositorios. Mantener diagnóstico y recomendaciones independientes de la implementación posterior; no revelar secretos ni datos personales.

La revisión técnica es de solo lectura. Los cambios se aprueban por separado y se implementan mediante PR. No inferir que una funcionalidad está en producción por estar presente en una rama.
